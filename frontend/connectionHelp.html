Connect this app to your SmartBook server

This page is the app itself. It can run on a shop computer (your server) or be installed from a hosted link (GitHub Pages / Firebase Hosting). If you installed it from a hosted link, tell it where your real server is - once. The address is remembered on this device.

Option 1 - Everyone is on the same Wi-Fi

  1. On the computer running SmartBook, press Windows key + R, type cmd and press Enter.
  2. Type ipconfig and press Enter. Look for IPv4 Address, for example 192.168.1.10.
  3. In the app login screen, in the server address box, type:
    http://192.168.1.10/api (use your number) and tap Save and test.
  4. Sign in with your username and password.

Option 2 - Server is on the internet (recommended for many shops)

Put backend/ + public/ + config/ on any PHP & MySQL hosting, then enter https://your-domain.com/api in the app. The app shell (this page) can stay on free static hosting - only the API needs PHP hosting.

Option 3 - Own computer only

If you run the app on the same computer that runs the server, no setup is needed - it connects to /api automatically (use http://127.0.0.1:8080 in a browser).

Tell the server address not to include a trailing slash. To change it later, use the connection box on the login screen again.
